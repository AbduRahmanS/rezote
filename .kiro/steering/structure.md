# Code structure

```
packages/ui/              shadcn/ui components (src/components), cn() helper, Tailwind theme (src/globals.css)
packages/core/            the skeleton (must stay app-agnostic: no import from apps/)
  src/event.ts            event model, canonical order, merge
  src/crypto.ts           keys, seal/open, writers-only fields
  src/links.ts            write and read share links
  src/storage.ts          IndexedDB: events, outbox, rejected, meta
  src/sync.ts             sync engine (TanStack Store for status and ghosts) and HTTP transport
  src/app.ts              defineApp + runtime (RezoteApp, state in a TanStack Store)
  src/node.ts             client without IndexedDB, for scripts
  src/format.ts           FCFA, kg, liters, dates, durations
  src/react/              AppShell (header, sync pill, menu sheet, bottom nav), widgets, dialogs, hooks
  src/worker.ts           Worker request handling: SPA shell with security headers, /api passthrough
  security.mjs            security headers policy, shared by the Worker and scripts/build-sw.mjs
  vite.mjs                shared Vite config (Cloudflare + TanStack Start SPA mode + React)
  test/                   core tests (property-based where possible)
packages/sync-api/
  src/index.ts            createSyncApi({ apps }) → handle(request, env)
  migrations/             D1 schema shared by all apps
  test/                   API tests over a D1 shim on node:sqlite
apps/<app>/
  src/domain/             events.ts (Zod), project.ts (pure projection), text.ts, app.ts, *.test.ts
  src/routes/             TanStack Router file routes: __root.tsx, new.tsx, _app.tsx (gate), _app/*, api/$.ts
  src/components/         screens shared by several routes
  src/runtime.ts          createApp + per-phone settings stores (role, GPS) and hooks
  src/router.tsx          getRouter()
  src/server.ts           Worker entry (wrangler main): calls rezoteFetch from @rezote/core/worker
  src/styles.css          imports the theme, sets the app's accent color
  src/routeTree.gen.ts    generated by the router plugin; committed
  wrangler.jsonc          the Worker: D1 binding, rate limiter
scripts/                  size check, service worker, icons, demo seed
docs/                     research, deployment, guide for a third app
```

## Conventions

- Business rules live in `src/domain` and are tested there. Routes only read the view and call `app.emit`.
- Routes that need a space live under `_app/`; the `_app.tsx` layout shows the welcome, waiting, or role screen until the phone is ready.
- Event type names: `<app>/<entity>.<past-tense verb>`, for example `collecte/bundle.recorded`.
- Entity IDs are `crypto.randomUUID()` generated on the phone.
- Screens use `act()` to show errors to the user in French.
